## SOLMARA — Where the Sky Becomes the Sea

An art-deco travel poster for Solmara, a city of golden domes and white towers floating on islands in a rose-gold sky above a sea of clouds, airships drifting between the islands. Solmara does not exist — the poster is the whole point.

![Solmara travel poster](entry.png)

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024×1024 JPEG, 367,803 bytes) to `/output` (or `$MAKEFUN_OUTPUT_DIR`). No network, no dependencies beyond the Python standard library. The program refuses to publish anything that is not a complete JPEG inside the 1 MiB cap, and verifies the copy against the source by digest, so two runs always write the same bytes.
